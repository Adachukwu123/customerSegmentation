This project is a Power BI dashboard created to analyze marketing campaign data and understand customer behavior, purchasing patterns, and campaign performance.

Using a single dataset table, the dashboard transforms raw data into interactive visual reports that help identify trends, customer insights, and overall business performance.

⸻

Objectives

* Analyze customer demographics
* Understand purchasing behavior
* Evaluate marketing campaign performance
* Identify customer spending trends
* Create interactive business reports

⸻

Tools Used

* Power BI
* Power Query
* DAX

⸻

Dashboard Features

* Interactive charts and visualizations
* KPI cards for important metrics
* Customer spending analysis
* Campaign response insights
* Product purchase trends
* Dynamic filters and slicers

⸻

Key Insights

The dashboard helps provide insights into:

* Customer income distribution
* Product spending patterns
* Marketing campaign responses
* Customer demographics
* Purchase behavior trends

⸻

Data Preparation

The dataset was prepared in Power BI by:

* Cleaning unnecessary data
* Correcting data types
* Handling missing values
* Creating calculated measures for analysis

⸻

Skills Demonstrated

* Data Cleaning
* Data Visualization
* Business Intelligence Reporting
* DAX Calculations
* Analytical Thinking
* Dashboard Development in Power BI
